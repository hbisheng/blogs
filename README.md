# Blogs

<https://hbisheng.github.io/blogs/>

I write posts to organize my mental models of computer systems.

I want to build an understanding of the world. I think that is important and satisfying.

The point is not to understand *all* the details; one can never exhaust the world of knowledge. The point is to build *some* understanding: to clarify my thoughts, describe the world as I know it, and expand upon that understanding. Once I have a mental map of different things, I know where to dig when I am intrigued to learn more.
