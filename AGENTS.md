# Repository instructions

- This public repository is the single editing source for the articles published at `https://hbisheng.github.io/blogs/`.
- Keep exactly one commit in repository history. Amend that commit for updates and push with `--force-with-lease`; never add a second commit.
- Do not push unless the user explicitly asks for that specific publication action.
- Keep the remote on SSH.
- Use Hugo for the site and validate changes with `hugo --minify` before publication.
- Organize articles primarily by subject. Preserve each article's original writing date as secondary metadata.
- Do not add migration notices or links back to the former `bishengh.me` copies.
- Treat the writing as a personal blog, not as a complete or authoritative reference.
